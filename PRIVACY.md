# Keyboard Trigger — Privacy Notice

This project is free, libre, privacy-focused and open-source.

- No trackers, analytics, or advertising libraries are included.
- No internet permission is requested by the app.
- Local data: logs and debug reports are stored locally; debug reports are sanitized (emails, phone numbers, tokens masked) before user shares them manually.
- The built‑in diagnostics tool creates two versions of a log file (raw and sanitized) so users can compare and verify that personal information has been removed before choosing to send the sanitized copy.

If you have concerns, open an issue at the repository and we'll address them.
