# Privacy Policy

Libre Equalizer is a lightweight audio equalizer application that is **free, libre,
open-source software**. The application is designed with privacy as a first-class
concern and adheres to the following principles:

- **No trackers, analytics, or advertising libraries** are included in the app.
- The app **does not request any internet-related permissions**; it operates
  entirely offline.
- **No network connections are made** by the application under normal operation.
- **Local data** (such as logs or debug reports) remain on the device. When a
  user chooses to share a debug report, sensitive fields such as e-mail
  addresses, phone numbers, or access tokens are automatically sanitized. The
  user can review both raw and sanitized logs before sending.
- The source code is fully available under the **GNU General Public License v3**,
  ensuring that anyone may inspect, modify, and redistribute it.
- The project is **privacy-focused and ad-free**; there are no mechanisms to
  collect or sell user data.

## Data Collection

Libre Equalizer collects *no personal data* automatically. The only information
that may ever leave a user’s device is a debug report explicitly generated and
manually shared by the user. That report is sanitized to remove any personally
identifiable information.

## External Links

The application contains links to external resources (e.g., GitHub/Codeberg
repository, support email, donation pages). Clicking such links opens the
user’s browser or e‑mail client; the app does not communicate with those
services directly.
